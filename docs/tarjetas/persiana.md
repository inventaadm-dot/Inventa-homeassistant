# Referencia: Persiana — `custom:inventa-cover-card`

Persianas, cortinas, portones: estado y posición (*Abierta 65 %*), **barra arrastrable** para la
posición y botones **subir / detener / bajar**. Solo aparecen los controles que el equipo admite.

**Tocar / mantener:** tocar la tarjeta no abre la ventana de Home Assistant; para verla, **mantén
presionado** (½ s) o usa clic derecho.

```yaml
type: custom:inventa-cover-card
entity: cover.cortina_living
```

Opciones: `entity` (obligatoria), `name`, `icon`.
