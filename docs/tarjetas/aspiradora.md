# Referencia: Aspiradora — `custom:inventa-vacuum-card`

Estado (*Limpiando · hace 14 min*), **batería** (del equipo o de su sensor de batería) y acciones
**detener / iniciar o pausar / volver a la base**. Funciona también con cortacésped (`lawn_mower`).

**Tocar / mantener:** tocar la tarjeta no abre la ventana de Home Assistant; para verla, **mantén
presionado** (½ s) o usa clic derecho.

```yaml
type: custom:inventa-vacuum-card
entity: vacuum.robot
```

Opciones: `entity` (obligatoria), `name`.
